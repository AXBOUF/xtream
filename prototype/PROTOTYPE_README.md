
**入力項目:**
- 顧客の電話番号 ✓ 必須

- 洗車コース選択
- 支払い方法
- 施工者名
- 車両ナンバー
- 割引額
- 備考

## 💬 よくある質問 (FAQ)

### Q: インターネット接続は必須?
**A:** クラウド版では必須。スタンドアロン版はオフライン動作可能です。

### Q: データのセキュリティは?
**A:** クラウド版では業界標準の暗号化・定期バックアップ。スタンドアロン版はローカル保存で安心。

### Q: 複数店舗で使える?
**A:** プロトタイプはシングル店舗版。クラウド版で複数店舗管理可能。

### Q: 既存システムとの連携は?
**A:** CSV エクスポート機能で既存システムとの統合可能。

### Q: 導入費用は?
**A:** スタンドアロン版: ¥0、クラウド版: ¥5,000～/月
